# **App Name**: CMS App Studio

## Core Features:

- Live App Preview: Interactive preview: Display a live, interactive preview of the app's UI on a simulated Android or iPhone device within the platform. Users can see changes in real-time as they customize widgets and layouts.
- Visual App Composer: Drag-and-drop UI builder: Provide a selection of pre-designed widgets (e.g., product grids, banners, forms) that users can drag and drop onto the app preview to design their mobile interface.
- Platform Connector: CMS Integration: Allow users to select their CMS platform (Prestashop, WooCommerce, Magento, OpenCart, Shopify) and configure API connections to link their app to their existing e-commerce data.

## Style Guidelines:

- Primary color: Dark blue (#1A237E) for a professional and trustworthy feel.
- Secondary color: Light gray (#F5F5F5) for backgrounds and content separation.
- Accent: Teal (#00BCD4) for interactive elements and highlights.
- Clean and modern font for UI elements.
- Split-screen layout with the phone preview on the right and the widget panel on the left.
- Consistent use of simple, line-based icons for widgets and settings.
